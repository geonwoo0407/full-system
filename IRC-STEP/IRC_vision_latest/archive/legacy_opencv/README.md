# Legacy OpenCV prototypes

이 폴더는 YOLO26 통합 파이프라인 이전에 사용했던 OpenCV 기반 초기 실험 코드를 보관합니다.

- `find_direct.py`
- `find_ddirect.py`
- `look_ground.py`
- `look_gground.py`

현재 ROS 2 실행 경로와 `console_scripts`에는 등록하지 않습니다. 발표 기록과 과거 알고리즘 참고 목적으로만 유지하며, 경기용 실행에서는 `yolo26_detector`, `unified_vision_node`, `motion_decision_node`를 사용합니다.
